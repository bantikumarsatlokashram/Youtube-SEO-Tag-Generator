# YouTube SEO Tag Generator

🔗 **Live Tool:** [https://bkpkvideo.com/tools/Youtube-SEO-Tag-Generator/](https://bkpkvideo.com/tools/Youtube-SEO-Tag-Generator/)

---

## 🚀 Features

* ✨ **Premium Apple Glass UI**
  Modern Glassmorphism design with frosted glass panels, soft shadows, and smooth transitions.

* 🌗 **Dark / Light Mode**
  Fully responsive theme that adapts to user preference.

* 🧠 **Smart Chunking Algorithm**
  Automatically breaks down long, complex, and mixed-language titles into highly optimized SEO seed keywords, filtering out stop-words.

* ⚡ **Serverless JSONP Architecture**
  Connects directly to Google/YouTube Suggest API via JSONP, bypassing CORS issues, proxy failures, and Ad-blockers.

* 📏 **Strict 500-Character Guard**
  Ensures the generated tags never exceed YouTube's native 500-character limit.

* 🔥 **Smart Hashtag Generator**
  Extracts top 15 CamelCase hashtags customized for the video description.

* 📋 **One-Click Copy**
  Seamlessly copy your tags or hashtags to the clipboard with native visual feedback.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5
* **Styling:** Tailwind CSS (via CDN) & Custom CSS Variables
* **Logic & Functionality:** Vanilla JavaScript (ES6+)
* **APIs:** Google/YouTube Autocomplete API (via JSONP)
* **Icons:** FontAwesome 6

---

## 📌 How to Use

1. **Enter Keyword/Title**
   Paste your video title or core keyword in the input box.

2. **Add Modifiers (Optional)**
   Click on quick modifiers like `+ 2024`, `+ in Hindi`, or `+ Tutorial` to boost your long-tail SEO.

3. **Generate**
   Click **Generate SEO Tags**.

4. **Copy & Paste**
   Copy the Tags box content directly to your YouTube video details, and the Hashtags to the bottom of your description.

## ⚙️ Installation & Setup

Since this is a client-side only application, there is no complex backend setup required!

```bash
# Clone the repository
git clone https://github.com/bantikumarsatlokashram/Youtube-SEO-Tag-Generator.git

# Navigate to the directory
cd Youtube-SEO-Tag-Generator

# Open index.html in your browser
# You can use Live Server (VS Code) or simply double click the file.
```
